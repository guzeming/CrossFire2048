# 原始美术工作区

`ArtSource/` 保存资源制作、提取和转换过程中的原始文件。Unity 使用的成品已经位于 `Assets/`，打开工程、查看现有场景和运行客户端不需要这个目录中的原始大文件。

仓库默认保留 Python/PowerShell 制作脚本、Markdown 说明、README、许可证和生成提示词；`.gitignore` 排除了原始模型、音频、贴图、导出缓存和检查报告。本地已有文件仍保留在原位置。

当前完整原始工作区约 19.4 GiB。需要修改源模型或重新导出资源的协作者，应向资源维护者取得相应素材，并按原目录结构放回 `ArtSource/`；这些文件不会由普通克隆自动恢复。具体要求见各子目录 README，工具路径需按个人环境设置。某些脚本还依赖这里被排除的清单、报告和中间文件，因此请共享完整的相关制作目录。

若团队决定共同版本化原始美术文件，应先规划独立素材仓库或其他共享位置及 LFS 容量，再调整忽略规则。不要使用 `git add -f ArtSource` 一次性把全部导出缓存加入游戏仓库。
